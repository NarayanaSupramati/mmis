# MMIS 0.3.3 Demo

**Android 10+ · Solana Mainnet · Hackathon / beta**

- `.skr`, Solana-wallet and direct private-address messaging.
- Mainnet endpoint discovery and xxDK/cMix off-chain transport.
- Production Mobile Wallet Adapter identity and Digital Asset Links.
- Local history, aliases, QR sharing/scanning and foreground banners.
- Encrypted messaging identity/history backup and restore.
- Local conversation deletion and explicit retry controls.

cMix sends can fail, time out or arrive late. Sent to network is not a delivery/read receipt. Notifications are foreground-only. The registry is upgradeable. Compatibility with 16 KB page-size kernels is not claimed.

Distribution: **pending GitHub Release publication**. Candidate `mmis-0.3.3-demo.apk`, versionCode13, package `network.mmis.runtime`, minSdk29, targetSdk36, 193,406,492 bytes. APK and signing hashes are in [release metadata](../release.json) and [README verification instructions](../README.md#try-it).

No private signing material is distributed. Demo video is pending; pitch deck is omitted until available.
