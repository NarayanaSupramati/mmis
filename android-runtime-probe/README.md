# Money Moves in Silence — Android

Android10+ application for `.skr`, wallet and direct `sp1_` messaging through xxDK/cMix.

See the [product README](../README.md), [build guide](../docs/build.md), [architecture](../docs/architecture.md) and [privacy model](../docs/privacy-model.md).

The historical directory name is retained to avoid changing build paths. Lab/Debug is for developer devnet use; official Release/Hackathon targets Mainnet and requires private production signing. Unit fixtures live in `docs/fixtures`; device/operator test harnesses are deliberately excluded from this public distribution.
